# 曼谷快閃雙馬 2026 — 行程詳情（4日3夜）

**賽事**：Amazing Thailand Marathon Bangkok 2026 (ATMBKK)
**日期**：2026年11月27日（五）– 11月30日（一）
**模式**：星期五晚放工後飛，星期一晚返港（只請 1 日假）

---

## 航班（HK Express 直航，已核實）
| 方向 | 航班 | 日期 | 時間 | 價錢 |

| 香港→曼谷 | UO734 | 五 27/11 | 21:40→23:40 | HK$879 |

| **合共** | | | | **HK$1,814** |

---

## 住宿（近 Sanam Luang 起點 / Khao San Road 一帶）
建議入住 **Phra Nakhon（老城區）**，距離 Sanam Luang 起點步行約 10–15 分鐘，凌晨起步唔使搭車。
- 經濟之選（trvl 已核實每晚價）：Dancenter Khaosan Park (HK$59) / Collection O Khaosan Park (HK$59) / Au Bon Hostel (HK$64)
- 升級之選：Riva Surya、Amari Watergate、Royal Orchid Sheraton 等河景酒店（價錢另行查證）

## 每日行程

### 星期五 27/11 — 放工快閃出發
| 時間 (BKK) | 活動 |
|------|------|
| 18:30 | 香港收工，直接去機場（建議最少 2 小時前到，即 ~19:30 前到 HKG） |
| 21:40 | **UO734 起飛** |
| 23:40 | 抵曼谷素萬那普機場（BKK）→ 落地簽證/通關 → 酒店 |
| 01:00 | 抵酒店，食個宵夜，訓覺（聽日 04:00 起步，要早起身） |

### 星期六 28/11 — 半馬日 + 慢活
| 時間 (BKK) | 活動 |
|------|------|
| 02:00 | 起身，食輕量早餐，整裝 |
| 03:00 | 步行去 MBK 中心起點（21K 起點喺 Phaya Thai 路 MBK 對出） |
| 04:00 | **21K 半馬起步**（時限 3.5 小時） |
| 08:00 | 跑完，終點 Sanam Luang → 泰式完賽盛宴補給 |
| 09:30 | 回酒店沖涼休息 |
| 11:00 | 輕遊覽：大皇宮一帶 / 河畔／寺廟（量力而行，唔好攰親） |
| 14:00 | 泰式按摩（放鬆肌肉） |
| 16:00 | Expo 補領物品 / 買紀念品（詩麗吉皇后國家會議中心） |
| 19:00 | 夜市晚餐（考山路 / 帕空花市） |
| 21:00 | 早睡（聽日 02:00 起步） |

### 星期日 29/11 — 全馬日（主菜）
| 時間 (BKK) | 活動 |
|------|------|
| 00:30 | 起身，食碳水面/香蕉，整裝 |
| 01:00 | 步行去 Sanam Luang 起點（拉差丹嫩路 最高法院對出） |
| 02:00 | **42K 全馬起步**（時限 7 小時） |
| 09:00 | 跑完（目標），終點 Sanam Luang → 泰式盛宴慶功 |
| 10:30 | 回酒店，好好休息 |
| 14:00 | 賽後慶功午餐（泰菜） |
| 16:00 | 輕鬆遊覽/購物：河畔夜市 Asiatique 或 CentralWorld |
| 20:00 | 晚餐 + 早抖 |

### 星期一 30/11 — 輕鬆半日 + 返港
| 時間 (BKK) | 活動 |
|------|------|
| 08:30 | 早餐，check-out 寄存行李 |
| 09:30 | 大皇宮 / 玉佛寺（曼谷地標打卡） |
| 12:00 | 午餐 + 最後購物（手信：泰式小食、藥油、紀念品） |
| 16:00 | 回酒店取行李 → 去機場 |
| 17:00 | 抵素萬那普機場（國際線 3 小時前到穩陣） |
| 19:45 | **UO703 起飛** |
| 23:40 | 返抵香港 |
