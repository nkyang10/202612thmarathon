## 曼谷食買玩（跑步以外嘅行程）

除咗 4.5K 親子跑，曼谷仲有大量嘢玩。以下精選，全部可以夾入行程：

### 🏛 景點
| 景點 | 貼士 |
|------|------|
| **大皇宮 / 玉佛寺** | 曼谷必去，金碧輝煌泰式宮殿。建議朝早去避人潮，著衫要莊重（過膝裙褲）。 |
| **鄭王廟（Wat Arun）** | 昭披耶河畔最靚寺廟，日落時分金塔超上鏡，可搭船過河。 |
| **昭披耶河遊船** | 乘長尾船 / 觀光船遊河，兩岸大皇宮、鄭王廟、百年建築盡收眼底。 |

### 🍜 飲食
| 美食 | 貼士 |
|------|------|
| **泰式美食**（冬陰功、炒河、綠咖喱） | 曼谷美食多到數唔晒，路邊攤同高級餐廳都得。 |
| **芒果糯米飯** | 泰國必食甜品，甜品店同夜市都有。 |
| **夜市小吃** | 考山路、帕空花市、河畔夜市，邊行邊食。 |

### 🛍 購物
| 地方 | 貼士 |
|------|------|
| **洽圖洽週末市場**（Chatuchak） | 全球最大週末市集，手信、精品、陶瓷乜都有。只開週末（星期六去啱啱好）。 |
| **Siam / CentralWorld 商場** | 有冷氣嘅購物天堂，連鎖店、品牌、美食廣場。 |
| **夜市**（Asiatique 河畔夜市） | 河邊市集，買嘢 + 睇景 + 食嘢一次過。 |

### 💆 放鬆
| 活動 | 貼士 |
|------|------|
| **泰式按摩** | 跑完 4.5K 之後按摩放鬆肌肉，Full body 泰式按摩係曼谷必做。 |
| **河畔日落** | 搵間河邊餐廳/酒吧，睇日落 chill 下。 |
