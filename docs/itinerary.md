# 曼谷親子快閃跑 2026 — 行程詳情（3日3夜）

**賽事**：Amazing Thailand Marathon Bangkok 2026（ATMBKK）— **4.5K 親子跑**
**日期**：2026年11月27日（五）– 11月30日（一）
**模式**：星期五晚放工後飛，星期一晚返港（只請 1 日假）
**主賽事**：4.5K Family Run — **11月29日（日）06:45 起步** @ Sanam Luang（1小時時限，唔計時，行+跑都得）

## 住宿（近 Sanam Luang 起點 / Khao San Road 一帶）
建議入住 **Phra Nakhon（老城區）**，距離 Sanam Luang 起點步行約 10–15 分鐘，跑步當日唔使搭車。
- 經濟之選（trvl 已核實每晚價）：Dancenter Khaosan Park (HK$59) / Collection O Khaosan Park (HK$59) / Au Bon Hostel (HK$64)
- 升級之選：Riva Surya、Amari Watergate 等河景酒店（價錢另行查證）
